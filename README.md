# Thermal Chip Readout and Analysis

This repository contains code for reading out, calibrating, and analyzing thermal chip measurements. The current code and analysis scripts are designed for **two thermal chip readouts**. Additional modifications will be needed to integrate more thermal chips or expand the readout system.
